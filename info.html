GIF'd

Creates animated GIFs from iPhone spatial photos with depth-aware compositing.

Language JavaScript, Python
Server Python HTTP server
GitHub adrian3/GIFd  (Public)
GitHub Pages https://adrian3.github.io/GIFd/
What it does
  • Imports iPhone spatial HEIC photos by upload or drag and drop
  • Extracts the RGB image and depth map from each spatial photo
  • Previews depth motion live in the browser with adjustable strength and direction
  • Generates and exports animated GIFs with configurable frame count, size, and dithering
  • Maintains a local thumbnail library with delete controls
  • GitHub Pages hosts a static demo mode with sample images — no server required
How to use

Start the local server with python3 server.py, then open http://127.0.0.1:4173 in your browser. Upload a spatial .HEIC file, select it from the library, adjust depth strength and direction, then click Make GIF. Use the settings panel to tune frame count, width, and dithering before saving.

Requires python3, libheif, exiftool, and ImageMagick installed via Homebrew.

Built with
PixiJS WebGL renderer — drives the real-time depth preview and direction modes
Flask Python server — handles HEIC conversion, depth extraction, and GIF generation
ImageMagick GIF compilation from extracted frames
libheif HEIC decoding — extracts image and depth data from spatial photos
